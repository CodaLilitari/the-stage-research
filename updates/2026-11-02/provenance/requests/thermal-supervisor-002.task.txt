TASK thermal-supervisor-001
Design and implement a failure-aware SUPERVISORY thermal-protection layer for the nonliving reference panel, using Coda's executed two-node model (rc_transient.py) as the plant. Scope is the observability/control coupling raised by fault cases F3/F4 in the appended task section: a frozen sensor need not announce its own failure, and a 45 C trip on a failed sensor protects nothing. Treat 40 C surface / 60 C internal as arbitrary study comparators only.

Deliver: (a) a formal state machine (states, guards, latched faults, no automatic restart) using only signals a real panel could plausibly observe in this model: reported sensor temperature at 1 s samples, commanded body power, elapsed time, and optionally an assumed independent second sensor whose cost you must state; (b) residual-based fault detection using the plant model (predicted vs reported sensor temperature) with explicit detection-delay and false-alarm analysis under assumed measurement noise and parameter uncertainty (state the assumed ranges); prove or disprove detectability of rear-path loss and sensor freeze from these signals; (c) a standard-library simulator harness with deterministic fault injection (rear loss at arbitrary time, sensor freeze/bias/dropout, delayed actuator response) and a predeclared scenario matrix of at most 60 runs across H1/H2/H3; (d) unittests including counterexamples where any controller using only the reported sensor must fail; (e) a short statement of what the scheme can and cannot guarantee. No hardware recommendations, no biological claims.
