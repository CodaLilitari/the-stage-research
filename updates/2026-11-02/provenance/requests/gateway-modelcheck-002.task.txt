TASK gateway-modelcheck-001
The Stage's embodiment-interface work uses a file-relayed action gateway (First Leaf) between a model and a simulated point body. Coda wrote a lifecycle design (GW-ASYNC0) for admission, dispatch, stop, failure and unknown outcomes; a separate contributor is implementing it. Your task is independent verification of the DESIGN itself, before code exists.

Deliver: (a) an abstract state model of the gateway + relay + crash/restart points (admission, mark_dispatched, transition commit, export, record_failure, mark_unknown, resolve_unknown, stop, duplicate request replay, serialize/restore, crash between any two durable writes); (b) a standard-library explicit-state model checker (breadth-first, with state hashing and a configurable depth bound) that enumerates interleavings and checks the design's invariants: at most one unresolved action; duplicates never authorise redispatch; stop latches and never claims cancellation of dispatched/unknown work; only a verified transition advances sequence/tick/observation; known failure releases the slot without advancing; restored inconsistent state is rejected; post-commit export failure never replays a transition; (c) minimal counterexample traces for any invariant the design as written fails to guarantee, plus the smallest clarification to the design that removes each; (d) unittests for the checker itself (it must find seeded bugs in deliberately broken model variants); (e) a mapping from abstract actions to the original interface.py/relay.py functions, noting where the current code differs from the design. No hardware actuation.
