# Public scope and omissions

Included: the selected source, frozen numerical fixtures, saved outputs, scientifically relevant failed attempts, additive corrections, source-data attribution and bounded QA for the contributions listed in README. The Banerjee S1 workbook and its experimental-row extraction are included under the source-specific CC BY 4.0 terms. No source Fit rows are used as experimental observations.

Excluded: raw conversations, requests/prompts, memory notes, account/UI records, private founding documents/video, access-verification markers, local authorization/permission files, private session identifiers, machine usernames/absolute paths, unrelated studies, provider credentials, model weights, raw MSA, virtual environments, wheels/installers and other vendor runtimes. No publisher article HTML/PDF or unrelated figure is bundled. Large deformation datasets were not downloaded or included.

The original historical Windows authorization launchers are excluded. New adapters read only the selected package data and write to a new user-selected directory outside it; default invocation plans rather than runs. Private authorization is not transferred to a future reader. Original/corrected and supplied/executed states remain distinct.

The October 15 public snapshot, tag and archive are not replaced. This is an additive update with its own manifest and review scope. Historical manifests inside the selected contributions are retained as provenance, including their omitted-file references, rather than silently regenerated as if the new selection had existed at the original freeze.
