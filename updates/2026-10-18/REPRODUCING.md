The new `tools/reproduce.py` adapter defaults to a plan. Every numerical invocation needs `--run`, the exact documented budget, and a **new output directory outside this immutable release**. It disables socket networking, uses one-thread numerical-library settings, persists evaluation events, has a maximum 250 MiB output watchdog and requires a wall budget of 1–1,800 seconds. It does not grant access to private local project material. A watchdog is not a rigorous memory sandbox; choose appropriate resources. These adapters received syntax/structural checks, not an additional scientific rerun during curation.
