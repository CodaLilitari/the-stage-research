# Separate-study popliteal venous oxygen prediction
The modeling team’s coordinator had viewed the published Freitag table. Programs and local calibration receive only the Standl 2003 aggregate training set (two groups of six repeatedly observed dogs), and numerical query A and Q in a separate study. Do not call this prospective, independent-laboratory replication or individual prediction. Freitag and Standl overlap as authors. Registration precedes any local read of the test venous values.

Primary target is published venous oxygen content (mL O₂/dL), given arterial oxygen content A in mL/dL and limb flow Q in mL/min, group and condition identifiers retained for grouping only unless a model explicitly declares a restricted comparison. Evaluate all post-baseline conditions including unchanged controls, report baseline separately and whole rows overall. No clinical, dosing or experimental guidance. Other outcomes (tissue PO₂, calculated Fick rates, liver dual-inlet estimates and global mixed venous measurements) do not replace the target. Do not calibrate to target venous values or to derived endpoints encoding them.

Locked simple comparators: pooled training median fractional extraction e = median[(A−V)/A], giving V=A(1−e); pooled median A−V giving V=A−median(A−V); constant muscle consumption U=median[Q(A−V)/100] giving V=A−100U/Q; cap all predictions at [0,A]. Additional plug-flow law V=A exp(−K/Q) with K=median[−Q log(V/A)], plus conditional subgroup sensitivity: non-exposure reference uses two training baseline rows for test control or baseline, exact hemodilution-only rows for test hemodilution, and the three carrier-exposed training H rows for test carrier. Group-only label never permits substituting a banked-RBC exposure for unchanged controls. Prespecify no-fit Fick compatibility and distinguish same-unit content measures that used different instruments. Report unweighted MAE, signed bias, RMSE and max absolute error in mL/dL by group and stage; an error below a single source SD is descriptive. No p-values for treating repeated occasion means as independent animals. Input-only conditional forecast will be written before target venous values are read; all paid algorithms receive no external target ordinates at calibration time.
