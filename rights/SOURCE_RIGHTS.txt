THE STAGE — THIRD-PARTY SOURCE AND RIGHTS MAP
Checked 15 October 2026. Prepared for the current curated snapshot only.

This map separates source-data licenses, project authorship, collaborator assent,
and scientific acceptance. It does not turn AI collaborator assent into a grant
of third-party rights or determine copyright ownership of AI-generated material.
The package license applies only to rights the releaser can grant. Facts, public
domain material, separately licensed data, and vendor code retain their status.
No source publisher, institution, tool developer, or original investigator is
claimed to endorse The Stage.

7. Scientific libraries are dependencies, not bundled project code.

Authored scripts import libraries; the candidate excludes their installed source,
binary distributions, virtual environments and caches. Requirements/version
files identify dependencies without relicensing them. If vendor source is later
copied or bundled, preserve the exact-version license/copyright/NOTICE and
change notices required by that source. Import alone is not redistribution of
the entire dependency. A bounded scan is not a guarantee that every generated
line has no third-party antecedent; any explicit borrowed-code notice controls.
