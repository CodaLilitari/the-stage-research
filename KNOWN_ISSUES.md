# Known failures, corrections and limits

These are retained findings, not a checklist of hypothetical risks. Historical reports describe their run-time state; this page supplies the current public interpretation.

| Work | Material limitation or failed check |
|---|---|
| HC0 | Equilibrium saturation/content differences are not tissue delivery flux. The carrier and rate parameters are hypothetical, not a fit to a human blood substitute. |
| PF0 | 55 of 144 cases cross an assumed threshold. One of seven internal checks failed: increasing wall permeability reduced the minimum in two coupled cases. The counterexample and diagnostic remain; there is no global monotonicity guarantee. |
| OK0 | The original numerical method erased tiny contact effects. The corrected finite-rate parcel model passed the declared checks but still underflows at extreme times near 1e-200. It alternates clamped phases, not two finite CSTRs. The corrected optimum is about 41.299770 in the hypothetical coupled-rate scenario; affinity need not increase through slower unbinding. |
| HB-FOLD1/2 | The poor single-sequence fold is retained (mean pLDDT 44.815; 140-CA RMSD 12.374 Å). MSA-assisted FOLD2 improves to 68.034 and 2.978 Å for this known target. One model/seed, no heme/tetramer/function test. 4,522 input alignment rows with 1:1 caps do not mean 4,522 retained model rows or only one homolog's information. |
| BH0 | Three actuators at eight repeated tissue-count settings are not 24 independent biological replicates. Figure 3A's 15 observations per condition do not establish independent n=15 or pairing. Oxygen limitation is not measured by these force files. |
| Nua PF-DATA1 | Source-table grouping, uncertainty and mechanistic interpretations required corrections. The three 144-case transport scenarios give 144, 143 and 138 threshold passes; 400 µm is not generally acceptable. Complete subject-table replay requires excluded source material. Native v2 code is a distinct returned revision, not retroactively covered by Coda's earlier execution. |
| Grok Bot / MECH1 | A ten-channel hydraulic calculation fails the selected radial oxygen bound before axial loss. The 4,512-case screen uses hypothetical territory, wall and budget assumptions; hydraulic power omits motor/controller losses. Capacity does not imply equal usable unloading or flow reduction. |
| Grok Build | Supplied original code passed its 43 checks but only 8/29 added boundary cases. A tolerance admitted positive demand at zero power/flow. Coda's derivative passed 29/29 and 11 Decimal comparisons, with the 105 ordinary-grid rows unchanged. The same local implementation author supplied those correction checks; no distinct review of the derivative is claimed. |
| Cowork cloud PF1-S | Original 972 cases/460 threshold passes replayed. Its source-demand unit interpretation was wrong. Corrected synthetic 729-case grids give 703 passes on the old mesh and 702 with the layer aligned. One near-threshold classification changes. The remaining source arithmetic discrepancy is unresolved. The fixed-wall rectangle has no finite axial supply budget; 0.05 mol/m³ is an assumed threshold, not viability. |
| Cowork local | Partial delivery: 17 files, 2,520 input combinations and 17,640 AL1 rows; final report and author manifest unfinished. Eight AL1 checks and eleven PF0 checks are author checks. Coda's receipt establishes files/counts, not independent numerical reproduction. |
| Gemini | The original compilation invents SDs from source ranges and mixes measurement conditions. NO/radius and affinity/redox relationships are illustrative. Local execution does not validate its ranking, uncertainty or synthetic held-out Hill examples as physiology. |
| Meta | Native CSV/Python/JSON files were not recovered. Only the exact bounded contribution/correction note is included; there is no completed, independently executed Meta module. |
| PA0 | The 41-case synthetic fixture validates the implemented checks on tested cases. Released fixtures are no longer sealed holdouts. It supplies no LLM identity, memory continuity or OS isolation evidence. |
| FL0 | SW1's sensor-only control was invalid and is retained as superseded. SW2 uses the corrected control. Public credit edits change historical self-hash bindings; use a separately prepared local run rather than claiming the public bytes equal the original frozen run. |
| MP0 / adapter | The probe's permutation control happened to be the identity in 2/64 settings. The adapter is a bounded simulator sensor/action path, not ongoing body revision or a physical controller. |
| Lily FL1-R | All ten planned contrast dictionaries match in Coda's full replay, but 2,084 trial hashes differ and one clean/shuffled seed 10237 has a material cross-runtime trajectory difference. This is not all-byte reproduction. The cause remains unresolved across the original and local Python/OS environments. |
| Gateway | Pending double-admit and commit-after-stop primitive gaps remain relevant to a future asynchronous integration; normal serial relay locking masks them. A 12,007-byte depth-6000 JSON input raises an uncaught RecursionError. It changes no state and releases the lock, but lacks the promised rejection receipt. These are blockers before async/action-enabled model use, not evidence of physical exposure. |
| MuJoCo parity | The 480-step MuJoCo 3.16 check covers a point-mass model to the stated 1e-10 tolerance. It is not a two-link robot check or validation of every proposed simulator adapter. |
| PX1 / CT1 | 270 mathematical integrations were checked. CT1 is a specification and planner, not an executed coupled tissue-support system. |

Within-project independent checks are evidence about the stated equations, code and saved artifacts, not external laboratory replication or clinical validation. The published-data analyses do not experimentally validate the project's tissue-support assumptions.
