HB-FOLD1: LOCAL HUMAN ALPHA-GLOBIN SINGLE-SEQUENCE CALIBRATION
Executed 2026-10-15 after HB-STRUCT0. Installation and a bounded GPU prediction completed. The predicted structure was poor against the experimental references; it is retained as a failure baseline, not presented as biological success.

EXACT INPUT AND PROVENANCE
The input is the 141-residue alpha-chain sequence in the experimental RCSB 2DN1 mmCIF. The source URL and retained-file hashes are in download_receipt.json. UniProt P69905 official JSON (https://rest.uniprot.org/uniprotkb/P69905.json, downloaded locally to raw/P69905.json) verifies that the input is exactly its 142-residue translation without the initial methionine. UniProt annotates initiator Met 1 as removed and the mature chain as positions 2-142. Thus predicted/mature/PDB author residue i = UniProt translation residue i+1. The input begins Val, not the precursor initiator Met. No proprietary sequence was used.

The predictor received the FASTA sequence only. No reference coordinates, heme, oxygen ligand, sequence alignment search, template or MSA-server submission was supplied. The input A3M contains the query alone. Experimental structures stayed in the evaluation path. Native hemoglobin's heme and quaternary environment are absent from this isolated chain prediction. A 2006 known structure can be present in model training data; this is pipeline calibration, not a held-out generalization test.

RUN CONFIGURATION AND LIMITS
AlphaFold2-ptm model 3, seed 0, one seed, one model, one recycle, single-sequence MSA, max-MSA 1:1, no templates, no relaxation, fast compilation, no sequence padding. Exact arguments, input/selected-weight hashes and dependency-lock hash were frozen before launch in fold_run_freeze.json. Environment set preallocation false, XLA memory fraction 0.28, TF unified memory 0, and two OpenMP/OpenBLAS threads. The monitor stopped only its own process group on RSS above 4 GiB, global GPU free memory below 2048 MiB, or wall time over 420 seconds.

An initial startup was deliberately terminated after source inspection showed the --disable-unified-memory CLI option deletes both the unified-memory setting and the requested XLA memory-fraction setting. That startup produced no prediction. Its freeze, log and resource receipt are preserved under attempt1_* (actual elapsed 38.72 seconds, peak sampled RSS 1.03 GiB). The corrected run set TF_FORCE_UNIFIED_MEMORY=0 explicitly and omitted that CLI flag. Downloader development also stopped safely on an incorrect expected archive-size literal, a ./ filename prefix and the archive LICENSE member; those validation checks were corrected before the complete receipt was produced. All ten parameter files and the license were eventually retained and hashed.

Return code 0; elapsed 45.905 seconds including startup. Sampled process-tree peak RSS 2,125,856,768 bytes (1.980 GiB). Global GPU memory used rose from 8640 MiB at the first sample to a maximum 13552 MiB, with minimum 2444 MiB free. CUDA timing warnings in fold_console.log warn that internal kernel timing had suboptimal accuracy; the monitor's wall-clock time is reported instead.

The generated 141-residue prediction has mean pLDDT 44.815, minimum 26.38, maximum 60.09; 96/141 residues have pLDDT below 50. Final log pTM 0.299, rounded to 0.30 in the output score JSON. Confidence scores are model outputs, not experimental validation.

This is poor structural recovery for this exact low-information configuration. It does not establish how a richer MSA, more recycles/models or other methods would perform, and it says nothing about oxygen affinity, toxicity, tissue regeneration, or clinical usefulness.
