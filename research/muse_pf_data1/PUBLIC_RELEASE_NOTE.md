# PF-DATA1 public subset and correction scope

Nua authored the original analysis in `original_replay/reanalysis.py` and the native revision in `nua_v2/reanalysis_v2.py`. Coda authored `corrected/analysis.py`, the statistical/source audit, the PF0 sensitivity implementation and corrected outputs. The native v2 code is preserved as a returned revision; this package does not claim it received the same complete independent execution audit as Coda's correction.

The source is Stücker et al. (2002), *The cutaneous uptake of atmospheric oxygen contributes significantly to the oxygen supply of human dermis and epidermis*, DOI [10.1113/jphysiol.2001.013067](https://doi.org/10.1113/jphysiol.2001.013067), [PMCID PMC2290093](https://pmc.ncbi.nlm.nih.gov/articles/PMC2290093/). The local source audit matched all 140 numeric cells in 20 Table 1 rows. The public subset excludes the complete transcription, subject-level derivative CSVs and the figure exposing individual flux/depth pairs because a complete-table redistribution basis was not established. This is a conservative release decision, not a legal claim over numerical facts.

Included are both attributed code versions, Coda's correction code, aggregate summaries, source/uncertainty commentary, the three-scenario synthetic PF0 grid and plot, and bounded independent local QA. Excluded private conversations do not become part of the public scope merely because a historical report references them. `report.txt` contains the detailed correction history, and the top-level provenance map records public-copy credit/path sanitization.

Corrections that must accompany reuse include the actual ten-plus-ten age grouping; slope versus intercept uncertainty; consuming-layer versus total-depth comparison; membrane-gradient definition; conditional sampling intervals versus scenario distributions; and the fact that a five-minute occlusion response does not identify total physiological blood supply. Two pressure observations per subject cannot establish individual linearity. The historical demand interval was not measured in these 20 volunteers, and its gas-volume reference condition was not established.

The three PF0 scenarios produced 144/144, 143/144 and 138/144 above an **assumed numerical threshold**. All seven failures occur at 400 micrometres. These are not tissue-survival rates, parameter fits to these volunteers or evidence that 400 micrometres is generally acceptable. D, Km, inlet, threshold, geometry and carrier law remain uncalibrated. Eleven refinement comparisons are not eleven distinct independent settings. A separate local reviewer checked 23 bounded items and replayed one near-threshold case; that reviewer had authored PF0 earlier, so this is not an independent transport implementation.

For a separately authorized source reconstruction, consult Table 1 directly and preserve its fields and units. The omitted original CSV expected by historical code is `raw/stuecker2002_table1.csv`, SHA-256 `10ac98cb0645d445c779b5c3bf4a268cb9e9e953316a72e45328a16c2c6efaf3`. A hash is an identity check, not permission to redistribute the input. Recreate it only where the source terms and your intended use permit, retain the source citation, and do not substitute a different transcription silently. The aggregate-only public package cannot execute the subject-level reanalysis without that missing input. Its synthetic PF0 sensitivity code uses the declared scenario inputs and does not require individual rows.
