# Scope of this snapshot

The file-level manifest and license map define the exact included bytes. Included are original scientific code, synthetic results, aggregate published-data analyses, permitted small source datasets, generated structural predictions, source-audit commentary, bounded QA receipts and retained failed cases. Historical statements such as “not published” describe the time those reports were written; this release's publication state is recorded separately.

Excluded are private raw conversations and account/session records, sign-in/access details, founding documents and their full-text derivatives, input video/audio, model weights, runtimes/caches, raw MSA, vendor source snapshots, copied full paper/website HTML/PDF, and unrelated personal material. No personal history is included in the synthetic PA0 archive.

The Stücker 20-row source transcription, duplicate individual outputs, native v2 subject CSV and scatter/depth figure are deliberately excluded because complete-table redistribution clearance was not established. Aggregate descriptive statistics, analysis code and synthetic PF0 outputs remain. [PF-DATA1 release note](research/muse_pf_data1/PUBLIC_RELEASE_NOTE.md) identifies the missing input and citation. This conservative selection is not a finding that scientific facts themselves are copyrighted.

The two small Dryad CSVs and PDB data are included under CC0; the UniProt JSON snapshot is under CC BY 4.0. The exact source notices control. The original Dryad README was not retrieved, so no reconstruction is presented as an original README.

Meta's native CSV/Python/JSON artifacts were not recovered. Only a bounded, newly authored contribution/correction note is included. Private conversation excerpts, surrounding chats and incomplete code are excluded. Source-access limitations are part of the result.

Long duplicate FL0 traces and duplicate local FL1-R rerun rows are omitted to reduce size. The delivered FL1-R fixtures/witnesses, summaries, code and local discrepancy reports are retained. Completed released fixtures must not be reused as sealed future holdouts.

Sanitization changes are limited to public human credits, personal runtime paths/access marker removal, an explicit historical source-pointer adaptation and a QA-scope wording correction. Original source bytes remain locally preserved; their SHA-256 and export SHA-256 are paired in `provenance/source_export_map.json`. No scientific results were recomputed during export. A historical hash that differs from a public copy is not evidence of a new execution.

Exact-export review scopes: Lily receives the complete candidate plus this map, license mapping, README and portfolio summary; Nua receives her exact selected code/aggregate subset and its correction note; Grok Bot receives his exact selected package plus correction context; Meta receives the exact limited note. Final review responses are separate from scientific acceptance. This file does not itself assert that those reviews have completed.
